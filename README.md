# KijaniKiosk DevOps Foundation

This repository contains the DevOps Starter Kit for the KijaniKiosk platform.

The project demonstrates:

- DevOps Flow, Feedback and Learning
- Git branching and pull request workflow
- Cloud service model selection
- AWS region and multi-AZ architecture
- IAM least privilege
- Public and private network segmentation

## Project Structure

The DevOps documentation and architecture artifacts are located in the `starter-kit` directory.

## Git Workflow

Development follows:

main → develop → feature branches → Pull Request → develop
